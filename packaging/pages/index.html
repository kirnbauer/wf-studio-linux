Flatpak repository

Installed from here, updates arrive through flatpak update and your software centre.

flatpak remote-add --user --if-not-exists wf-studio-linux https://kirnbauer.github.io/wf-studio-linux/wf-studio-linux.flatpakrepo
flatpak install --user wf-studio-linux dev.kirnbauer.WFStudioLinux

The repository is signed; the public key is embedded in the .flatpakrepo file. Key fingerprint: {{FINGERPRINT}}
